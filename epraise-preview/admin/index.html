The backend is not connected yet.

This dashboard is built and ready, but it has no database, authentication or image storage to talk to. Your website is static on GitHub Pages, so those three services must come from a managed backend.

What to do (about 10 minutes)

  1. Create a free project at supabase.com.
  2. Open SQL Editor and run the file supabase-schema.sql from this project.
  3. In Authentication → Users, create one user with your email and a strong password. This is you — there is no public sign-up.
  4. Run the last SQL block from that file with your email to make yourself the administrator.
  5. Open Project Settings → API and copy the Project URL and the anon public key.
  6. Paste both into the CFG block at the top of this file's script, then redeploy.

Until then this page will refuse to show a dashboard rather than pretend to work.
